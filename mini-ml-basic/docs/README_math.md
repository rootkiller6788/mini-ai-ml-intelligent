## 1. 线性模型

### 1.1 线性回归

**目标函数** (均方误差):

```
L(θ) = 1/(2n) ‖Xθ − y‖² = 1/(2n) Σᵢ (θᵀ x⁽ⁱ⁾ − y⁽ⁱ⁾)²
```

**梯度**:

```
∇_θ L = 1/n Xᵀ (Xθ − y)
```

**解析解 (Normal Equation)**:

```
θ* = (XᵀX)⁻¹ Xᵀ y
```

复杂度 O(nd² + d³)，当 d 很大时不适用，需转为迭代方法。

**SGD 更新规则** (批量大小为 B):

```
θ := θ − η · (1/|B|) Σ_{i∈B} (θᵀ x⁽ⁱ⁾ − y⁽ⁱ⁾) x⁽ⁱ⁾
```

**动量法 (Momentum)**:

```
v := β · v − η · ∇_θ L
θ := θ + v
```

β 典型值 0.9，积累历史梯度方向，加速收敛。

---

### 1.2 逻辑回归

**模型**:

```
P(y=1 | x; w) = σ(wᵀ x + b) = 1 / (1 + exp(−(wᵀ x + b)))
```

**二分类交叉熵 (BCE)**:

```
L(w) = − 1/n Σᵢ [yᵢ log σ(zᵢ) + (1−yᵢ) log(1−σ(zᵢ))]

其中 zᵢ = wᵀ x⁽ⁱ⁾ + b
```

**梯度**:

```
∂L / ∂w = 1/n Xᵀ (σ − y)

∂L / ∂b = 1/n Σᵢ (σ(zᵢ) − yᵢ)
```

注意：此处的 σ 表示向量化的 sigmoid，与线性回归在梯度形式上
非常相似，区别在于预测值经过了 sigmoid 非线性变换。

---

### 1.3 Softmax 多分类

**模型**:

```
P(y=k | x) = exp(zₖ) / Σⱼ exp(zⱼ)

其中 zₖ = wₖᵀ x + bₖ
```

**交叉熵损失**:

```
L = − 1/n Σᵢ log P(y⁽ⁱ⁾ | x⁽ⁱ⁾)
```

**梯度**:

```
∂L / ∂wₖ = 1/n Σᵢ (P(y=k|x⁽ⁱ⁾) − 1[y⁽ⁱ⁾=k]) x⁽ⁱ⁾
```

即在真实类别减去 1，其余不变。这被称为 "autograd-like" 的
梯度计算方式——反向传播时从交叉熵损失开始，经过 softmax 层
得到简洁的梯度形式。

## 2. 支持向量机

### 2.1 硬间隔 SVM

原始问题 (Hard Margin):

```
min_{w,b}  ½‖w‖²
s.t.       yᵢ (wᵀ xᵢ + b) ≥ 1, ∀i
```

当数据线性不可分时无解。

### 2.2 软间隔 SVM (C-SVM)

```
min_{w,b,ξ}  ½‖w‖² + C Σᵢ ξᵢ
s.t.         yᵢ (wᵀ xᵢ + b) ≥ 1 − ξᵢ,   ξᵢ ≥ 0
```

等价的无约束 Hinge Loss 形式:

```
L(w,b) = ½‖w‖² + C Σᵢ max(0, 1 − yᵢ (wᵀ xᵢ + b))
```

代码实现中除以 n 得到平均损失，梯度为:

```
∂L/∂w = w − C Σ_{i: yᵢ(wᵀxᵢ+b) < 1} yᵢ x⁽ⁱ⁾
∂L/∂b =   − C Σ_{i: yᵢ(wᵀxᵢ+b) < 1} yᵢ
```

---

### 2.3 核技巧 (Kernel Trick)

将内积 x·x′ 替换为核函数 K(x, x′):

| 核函数       | 公式                                  | 参数           |
|------------|---------------------------------------|--------------|
| 线性         | K(x,x′) = xᵀ x′                      | 无            |
| 多项式       | K(x,x′) = (γ xᵀ x′ + r)^d            | γ, r, d     |
| RBF (Gaussian) | K(x,x′) = exp(−γ‖x−x′‖²)            | γ            |

引入核技巧后，SVM 的决策函数:

```
f(x) = Σᵢ αᵢ yᵢ K(xᵢ, x) + b
```

其中 αᵢ 为对偶变量（Lagrange multipliers），只对支持向量 (αᵢ>0)
非零。

---

### 2.4 SMO (Sequential Minimal Optimisation)

每次选取两个违反 KKT 条件的 αᵢ, αⱼ，解析求解其最优值，
保持等式约束 Σ αᵢ yᵢ = 0。这是解决 QP 问题的高效算法。

本库提供了 API 框架 (`smo_take_step`, `smo_examine_example`)，详细
实现标记为占位，用户可通过梯度法学习线性 SVM。

## 3. 决策树与随机森林

### 3.1 分裂准则

**Gini Impurity** (用于 CART):

```
Gini(D) = 1 − Σₖ pₖ²

ΔGini = Gini(parent) − (|Dₗ|/|D|) Gini(Dₗ) − (|Dᵣ|/|D|) Gini(Dᵣ)
```

**Entropy & Information Gain**:

```
Ent(D) = − Σₖ pₖ log₂ pₖ

IG(D, feature) = Ent(D) − Σ_{v∈Values} (|Dᵥ|/|D|) Ent(Dᵥ)
```

---

### 3.2 剪枝

**预剪枝 (Pre-Pruning):**

在构建过程中设定停止条件:
- `max_depth`: 树的最大深度
- `min_samples_split`: 节点最少样本数才允许继续分裂

**后剪枝 (Post-Pruning):**

从底向上，对每个内部节点：若将其替换为叶子节点后验证集准确率
不下降，则执行剪枝。本库 API 就位，实现为占位。

---

### 3.3 随机森林

**Bootstrap Aggregating (Bagging):**

每棵树在大小为 N 的数据集中有放回采样 N 个样本创建训练集。
期望约 63.2% 的样本被选中（OOB 误差估计）。

**Feature Bagging:**

每个节点随机选取 m (默认 √d) 个特征进行分裂，降低树间相关性。

**预测:**

- 分类：多数投票
- 回归：平均

## 4. 集成学习与 Boosting

### 4.1 AdaBoost

**权重更新公式:**

```
εₜ = Σᵢ wᵢ⁽ᵗ⁾ · 1[hₜ(xᵢ) ≠ yᵢ]        (加权误差)

αₜ = ½ ln((1−εₜ) / εₜ)                (分类器权重)

wᵢ⁽ᵗ⁺¹⁾ ∝ wᵢ⁽ᵗ⁾ · exp(−αₜ yᵢ hₜ(xᵢ))
```

最终强分类器:

```
H(x) = sign(Σₜ αₜ hₜ(x))
```

指数损失函数:

```
L = Σᵢ exp(−yᵢ f(xᵢ))
```

AdaBoost 可视为在指数损失下的前向逐步加性建模。

---

### 4.2 Gradient Boosting (GBDT)

**通用框架:**

```
初始化: F₀(x) = argmin_γ Σᵢ L(yᵢ, γ)

for t = 1 to T:
    r̃ᵢₜ = − [∂L(yᵢ, F(xᵢ)) / ∂F(xᵢ)] |_{F=Fₜ₋₁}      (负梯度)
    用弱学习器 hₜ 拟合 r̃ₜ
    选择步长: γₜ = argmin_γ Σᵢ L(yᵢ, Fₜ₋₁(xᵢ) + γ hₜ(xᵢ))
    更新: Fₜ(x) = Fₜ₋₁(x) + ν γₜ hₜ(x)
```

ν 为学习率 (shrinkage)，通常 0.01 ~ 0.1。

**回归任务 (L2 损失):**

负梯度即为残差: r̃ᵢₜ = yᵢ − Fₜ₋₁(xᵢ)

**分类任务 (对数损失):**

负梯度 = 真实标签 − 预测概率，类似逻辑回归梯度。

---

### 4.3 XGBoost 核心创新

**二阶泰勒近似:**

目标函数在 ŷ⁽ᵗ⁻¹⁾ 处展开:

```
Obj⁽ᵗ⁾ ≈ Σᵢ [gᵢ fₜ(xᵢ) + ½ hᵢ fₜ²(xᵢ)] + Ω(fₜ)

其中:
  gᵢ = ∂_{ŷ⁽ᵗ⁻¹⁾} l(yᵢ, ŷ⁽ᵗ⁻¹⁾)   (一阶梯度)
  hᵢ = ∂²_{ŷ⁽ᵗ⁻¹⁾} l(yᵢ, ŷ⁽ᵗ⁻¹⁾)  (二阶梯度 / Hessian)
  Ω(fₜ) = γ T + ½ λ Σⱼ wⱼ²          (正则化)
```

**叶子最优权重:**

对于固定树结构 q(x):

```
wⱼ* = − Σ_{i∈Iⱼ} gᵢ / (Σ_{i∈Iⱼ} hᵢ + λ)
```

其中 Iⱼ = {i | q(xᵢ) = j} 是落在叶子 j 的样本集合。

**最优目标值:**

```
Obj* = −½ Σⱼ ( (Σ gᵢ)² / (Σ hᵢ + λ) ) + γ T
```

分裂时选择使 Obj* 降低最大的特征-阈值对（Gain = Obj*_before − Obj*_after）。

---

### 4.4 Stacking

使用 K 个基础模型生成元特征，再用元学习器组合:

```
训练阶段:
对每个 i, 生成元特征 zᵢ = (h₁(xᵢ), h₂(xᵢ), ..., hₖ(xᵢ))
用 (zᵢ, yᵢ) 训练元学习器

预测:
ŷ = g(z) = g(h₁(x), h₂(x), ..., hₖ(x))
```

本库元学习器默认为等权平均 (可通过替换 meta_coefs 改动)。

## 5. 聚类算法

### 5.1 K-Means

**目标** — 最小化簇内平方和 (WCSS / Inertia):

```
J = Σ_{k=1}^K Σ_{i∈Cₖ} ‖x⁽ⁱ⁾ − μₖ‖²
```

**Lloyd's Algorithm:**

```
重复:
  分配: c⁽ⁱ⁾ = argminₖ ‖x⁽ⁱ⁾ − μₖ‖²
  更新: μₖ = (1/|Cₖ|) Σ_{i∈Cₖ} x⁽ⁱ⁾
直到: 标签不再变化 或 质心位移 < tol
```

**k-means++ 初始化:**

确保初始中心点彼此距离较远，加速收敛并提高质量。

```
c₁ ← 均匀随机
for k = 2..K:
    D(x) = min_{j<k} ‖x − cⱼ‖²       (到最近已有中心的距离)
    以概率 D(x) / Σᵢ D(xᵢ) 选择 cₖ
```

k-means++ 是 O(log K) 近似最优的初始化。

---

### 5.2 DBSCAN

密度定义:
- ε-邻域: N_ε(x) = {x′ : dist(x, x′) ≤ ε}
- 核心点: |N_ε(x)| ≥ min_pts
- 边界点: |N_ε(x)| < min_pts 但属于某核心点的 ε-邻域
- 噪声点: 既非核心也非边界

**算法:**

```
对每个未访问点 p:
    标记为已访问
    N = ε-邻域(p)
    if |N| < min_pts:
        标记 p 为噪声
    else:
        创建新簇 C
        扩展簇(p, N, C, ε, min_pts)
```

时间复杂度 O(n log n) 用 R-tree，朴素为 O(n²)。

---

### 5.3 层次聚类 (Agglomerative)

**通用流程:**

```
初始化: 每个点是一个簇
while 簇数 > 目标:
    计算所有簇对的距离矩阵
    合并距离最近的两个簇
```

**Linkage 距离定义:**

| Linkage  | 公式                                              |
|----------|--------------------------------------------------|
| Single   | d(C₁,C₂) = min{ d(a,b) : a∈C₁, b∈C₂ }           |
| Complete | d(C₁,C₂) = max{ d(a,b) : a∈C₁, b∈C₂ }           |
| Average  | d(C₁,C₂) = 1/(|C₁||C₂|) Σ_{a,b} d(a,b)          |

Single-link 产生链条效应，Complete-link 倾向于球形紧凑簇。

## 6. 评价指标

### 6.1 Silhouette Score

```
s(i) = (b(i) − a(i)) / max{a(i), b(i)}

其中:
  a(i) = 点 i 到同簇其他点的平均距离
  b(i) = 点 i 到最近的外簇所有点的平均距离

全局 Silhouette = 1/n Σᵢ s(i) ∈ [−1, 1]
```

解释:
- +1: 点远离邻近簇，良好嵌入
- 0: 点在两个簇的边界
- −1: 点更接近邻近簇，可能被错误分配

---

### 6.2 混淆矩阵与派生指标

```
                Predicted +   Predicted −
Actual +           TP             FN
Actual −           FP             TN
```

| 指标             | 公式                     |
|----------------|------------------------|
| Accuracy       | (TP+TN) / (TP+TN+FP+FN) |
| Precision      | TP / (TP+FP)            |
| Recall         | TP / (TP+FN)            |
| F1-Score       | 2·Prec·Rec / (Prec+Rec)  |

---

### 6.3 ROC-AUC

ROC 曲线绘制 TPR vs FPR 在不同阈值下的表现。AUC 表示模型将
正例排在负例之前的概率。逻辑回归、SVM 等概率模型可通过调整
决策阈值获得 ROC 曲线。
